# PeptideLab

**PeptideLab** is a web platform developed as part of an **Undergraduate Scientific Initiation Research Project (PIBIC/UNIR)** for proteogenomic analysis, variant processing, and integration of proteomic results.

The platform combines the generation of variant-derived search resources with tools for candidate comparison, validation, annotation, and interpretation. It also integrates **ESM-1v** for sequence-context assessment of missense variants.

This repository contains the PeptideLab frontend application, which communicates with the platform backend through a REST API.

## Main Features

### Peptide Processor

- Processes variants from text input or plain text files (.txt, .tsv, .csv).
- Supports missense, indel, frameshift, and stop-loss variants.
- Retrieves reference protein sequences.
- Reconstructs variant-containing protein sequences.
- Generates variant-derived peptides and proteomic search resources.
- Preserves provenance between variants, proteins, and peptides.
- Exports processed results.

### Analysis Tool

- Imports and interactively explores proteomic search results.
- Associates peptides with proteins and normalizes protein identifiers.
- Compares assignments obtained from reference and variant-derived databases.
- Applies configurable multicriteria filtering based on spectral evidence.
- Performs exact peptide verification using resources generated by the Peptide Processor.
- Recovers peptide and variant provenance.
- Supports gene annotation and protein identifier conversion.
- Assesses missense variants with **ESM-1v** using the protein sequence provided in the analysis sheet as context.
- Organizes, filters, and exports prioritized candidates for downstream analysis.

## Technologies

### Frontend

- **React 18**
- **TypeScript**
- **Vite**
- **Material UI (MUI v5)**
- **React Router v7**
- **React Hook Form**
- **Zod**

### Platform Backend

PeptideLab uses a Python backend based on:

- **FastAPI**
- **Pydantic**
- **SQLAlchemy**
- **PostgreSQL**

The frontend communicates with the backend through a REST API.

## Development

```bash
npm ci
cp .env.example .env    # VITE_API_URL points to the backend API
npm run dev             # development server
npm test                # component tests (vitest)
npm run lint
npm run build           # type checks and production build
```

The `Dockerfile` builds the app with `VITE_API_URL=/api/v1` and serves it with Nginx on port 80; the API is expected under `/api` on the same domain.

## Research Context

PeptideLab was developed at the **Federal University of Rondônia (UNIR)** as part of a PIBIC undergraduate research project focused on computational strategies for proteogenomic analysis and the investigation of variant-derived peptides.

The platform is designed to connect variant-derived database generation, proteomic evidence, peptide-level provenance, annotation, and sequence-context variant assessment within an integrated and auditable workflow.
